# Pactwright workspace

This directory is reserved for the installed Pactwright version.

Do not hand-author unverified Pactwright runtime/configuration schemas here. Initialise or synchronise this directory using the Pactwright version selected by the project, then commit the resulting canonical files and lock information.

The Worldstack roadmap in `specs/graph/intents/` is intentionally plain Markdown so the repository can be bootstrapped before binding it to a specific Pactwright storage schema.
