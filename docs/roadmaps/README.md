Once initialised, canonical graph records and accepted evidence own progress. Generate or reconcile these public summaries from that authority; do not maintain a parallel manual status system.

## Later direction

Roadmap 01 establishes the engineering and experiment foundation through physical-system compositions and permanent test games. It ends before a full city-block vertical slice.

Later planning should use its programme Graph Review to select cross-disciplinary questions and the smallest experiments capable of testing them. Physical, cognitive, social, economic and institutional models may then be composed where the question requires them. Keep observations, hypotheses and real-world validation distinct under [specification 03](../specs/03-experimentation-evidence-and-emergence.md).

The [development ladder](../specs/04-game-world-and-representation.md#development-ladder) continues through vertical slices, world slices, open-world integration and selective fidelity promotion. Existing games remain regression fixtures as this work grows. Detailed later milestones depend on evidence from Roadmap 01; this direction does not authorise a new subsystem or a second implementation roadmap.
