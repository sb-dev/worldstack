# Game, World and Representation

## Purpose

Define the flagship open-world game as Worldstack's first large integration environment and keep simulation state distinct from presentation.

## State versus representation

```text
WORLD STATE ≠ WORLD REPRESENTATION
```

A simulated state such as rain, congestion, rent pressure or cultural activity may be represented through rendering, architecture, traffic, NPC behaviour, dialogue, radio, music, advertising or other media.

Creative Production Skills materialise state. They do not become the authority for the underlying model.

## Representation ladder

- L0: structured state/debug output.
- L1: primitive representation.
- L2: procedural low-detail representation.
- L3: art-directed prototype.
- L4: production asset.
- L5: hero-quality asset.

System maturity and presentation fidelity can progress independently.

## Development ladder

```text
Micro PoC
→ Capability PoC
→ Test Game
→ Integration Game
→ Vertical Slice
→ World Slice
→ Open-World Integration
→ Selective Fidelity Promotion
```

Test and integration games are permanent executable fixtures, not disposable demos. They may simultaneously serve as experiments, regression environments, benchmarks, Production Skills integration tests and gameplay prototypes.

## World breadth

The city should exist cheaply before it exists expensively. Map-derived structure, primitive geometry and streaming can validate world architecture before hero assets are authorised.
