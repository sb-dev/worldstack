# INT-003 - Production Skills Capability Baseline

## Intent

Classify the Production Skills needed by Roadmap 01 as available, partial, incubating, missing or not-yet-required.

## Dependencies

- INT-001

## Contract focus

Inspect the actual Production Skills repositories needed by Roadmap 01 and record capability coverage without requiring a central catalogue.

## Evidence target

A capability map exists without prematurely creating new skill repositories. Each classification is grounded in an inspectable skill repository or an explicit absence.

## Scope rule

A central Production Skills catalogue or incubator may absorb the findings later but is not a prerequisite for this Intent.
