# Initial Worldstack Intent Graph

This directory contains the bootstrap Intent backlog in plain Markdown.

It is intentionally not a hand-authored Pactwright storage schema. Once the repository is initialised with the selected Pactwright version, these Intents should be imported or recreated through the canonical Pactwright mechanisms and the generated graph state becomes authoritative.

See `docs/roadmaps/01-foundation-to-pursuit.md` for the dependency view.
